# Seed Data for Airbnb Clone

This folder contains SQL scripts to populate the Airbnb database with sample data.

## Tables Populated

- users
- states
- cities
- places
- amenities
- place_amenity (join table)
- reviews

## Sample Data Overview

- 2 users
- 2 states and 3 cities
- 2 places (each belonging to a city and a user)
- 3 amenities (assigned to places)
- 2 reviews

The sample data simulates basic real-world usage for testing queries and schema integrity.
